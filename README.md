## 网站文件

网站是无需构建步骤的静态 HTML、CSS 和 JavaScript 项目，页面与图片位于 [`dist/`](dist/) 目录。下载仓库后，可从 `dist/index.html` 开始浏览。在线站点由 Sites 托管；这个 GitHub 仓库保存网站源码和展示图片。

> [!NOTE]
> 封面齿轮图是装饰插画，五件作品的详情图为 SolidWorks 建模截图。作品展示不代表实物制造、性能验证或商业产品。
